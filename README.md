# UniStudy 📚

Una aplicación sencilla para que estudiantes universitarios organicen sus materias y estudien con más foco.

## Funciones

- Panel con resumen de tareas, materias y progreso.
- Gestión de materias y porcentaje de avance.
- Lista de tareas con fecha de entrega, prioridad y estado.
- Temporizador Pomodoro con sesiones de enfoque de 25 minutos y descansos de 5.
- Apuntes rápidos con guardado automático.
- Diseño adaptable a móvil y escritorio.

## Cómo usar

Abre `index.html` en un navegador moderno. No requiere instalación ni dependencias de servidor. Los datos se guardan localmente en el navegador mediante `localStorage`.

> Los datos quedan guardados en el dispositivo y navegador que uses. Si borras los datos del navegador, también se borrará la información de UniStudy.
